# Student Attendance Management System

A web-based student attendance management system developed using Python and Flask.  
The system helps manage student records and track daily attendance digitally.

## Features
- Secure admin login and session management
- Add and manage student records
- Duplicate roll number validation
- Daily attendance marking
- Date-wise attendance viewing
- Attendance summary and percentage calculation

## Technologies Used
- Python
- Flask
- SQLite
- HTML
- CSS

## Project Structure
- app.py – Main Flask application file
- templates/ – HTML templates
- static/ – CSS files

## How to Run the Project
1. Install Python
2. Install Flask using `pip install flask`
3. Run `app.py`
4. Open browser at `http://localhost:5000`
